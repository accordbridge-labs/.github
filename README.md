# AccordBridge organization resources

This public repository contains the organization profile and shared collaboration guidance.

- `profile/README.md`: public organization profile.
- `CONTRIBUTING.md`: planning contribution process.
- `SECURITY.md`: reporting guidance and current operational status.
- `ISSUE_TEMPLATE/`: issue templates.
- `PULL_REQUEST_TEMPLATE.md`: review prompts.

The application repositories are separate and initially private. No application implementation is included here.
