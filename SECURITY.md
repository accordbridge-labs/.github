# Security

## Current status

AccordBridge is a planning-stage project. There are no supported releases or deployed AccordBridge payment contracts. No real funds should be sent to addresses advertised as AccordBridge escrow deployments.

## Reporting

Do not publish secrets, private customer data, or exploit details in public issues. Use GitHub private vulnerability reporting on the affected repository if available. If it is unavailable, request a private reporting channel without disclosing the vulnerability.

A monitored security contact, incident-response ownership, and response targets must be established before a live pilot. No response-time commitment is currently offered.

## Before real funds

Require review of the exact deployed code and authority model, reproducible deployment evidence, meaningful authorization and accounting tests, monitoring, reconciliation, recovery procedures, and a functioning dispute process. An upstream audit does not automatically cover later changes or our integration.
