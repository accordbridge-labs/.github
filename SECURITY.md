# Security

## Current status

AccordBridge is an unaudited development/testnet prototype. Experimental Soroban escrow and a valueless faucet token have public deployment records. There are no supported production releases or mainnet payment contracts. Never send real funds to test deployments. Historical testnet records may become invalid after resets or storage expiry.

## Reporting

Do not publish secrets, private customer data, or exploit details in public issues. GitHub private vulnerability reporting is enabled on all three application repositories: open the affected repository's Security tab and choose Report a vulnerability. If that option becomes unavailable, request a private reporting channel without disclosing the vulnerability.

A monitored security contact, incident-response ownership, and response targets must be established before a live pilot. No response-time commitment is currently offered.

## Before real funds

Require review of the exact deployed code and authority model, reproducible deployment evidence, meaningful authorization and accounting tests, monitoring, reconciliation, recovery procedures, and a functioning dispute process. An upstream audit does not automatically cover later changes or our integration.
